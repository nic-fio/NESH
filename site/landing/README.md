# NESH landing page — the chosen direction

Mockup **05 «Glass»**, chosen by the owner on 2 October 2026 among 20 mockups
(same content, twenty visual directions): deep blue, gradients from the logo's
blue to its teal-green, frosted cards. It will be the page at
`https://nesh.nicfio.it` (see D21 in `docs/decisions-and-history.md`).

- `index.html` — the mockup, a self-contained page without JavaScript (fonts
  embedded and subset to the characters used).
- `preview.png` — the top of the page at 1440 × 900.
- `BRIEF.md` — the content and the rules the mockups followed: only true
  statements, program texts quoted exactly.

Published on 2 October 2026 by `site/publish.sh`, adapted: freeware licence,
downloads from the site, hardware reports to `nesh@nicfio.it`, search engine
metadata. Still to do: a new demo recording (the GIF shows 0.2.0), fonts
licensed for the web, a review of the few connecting sentences written for the
mockup.
